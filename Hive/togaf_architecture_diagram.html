Flows

兩條路徑如何穿過四層

API Platform：業務系統即時整合

  1. 呼叫端發出請求總部、產區或合作系統，經 Front Door＋WAF 與 Private Link 進入
  2. APIM 驗證與管控JWT／OAuth2 身分、限流、版本與 Policy；OpenAPI 契約集中管理
  3. 整合服務處理業務邏輯C# .NET 8 在 Container Apps：轉換、驗證、4-Gate 檢核、錯誤處理
  4. 呼叫 D365 官方介面Data Entities／OData；需非同步處理時交給 Service Bus
  5. 統一回傳信封成功或失敗都回傳標準格式與 TraceId；斷網時 Edge Proxy 先暫存

Data Lake：分析資料入湖

  1. D365 雲對雲同步Synapse Link 持續同步至 ADLS Gen2，不佔產區 SD-WAN 頻寬
  2. 產區 MS SQL 離峰擷取01:00–03:00 ADF 經 Self-hosted IR 增量打包傳輸，有頻寬限制與斷點續傳
  3. Bronze → Silver原樣落地後清洗：主鍵、刪除規則、公司別
  4. 每日對帳02:30 與 D365 財務訂單雙向勾稽，未解釋差異為 0
  5. Gold 供 BI 取數06:00 聯銓 BI 改由 Gold 層取數，晨會報表準時出爐
