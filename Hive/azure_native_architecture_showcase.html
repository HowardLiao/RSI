📌 選型策略升級定調（為什麼 Azure 原生架構應列為第一候選？）：
1. D365 F&O 核心壁壘：D365 採 C++ 核心雲端 SaaS，微軟嚴格封鎖底層資料庫日誌，無法直接掛載 Debezium、Datastream 或 DMS 等第三方 CDC。只有 Azure 原生 Synapse Link / Fabric Link 具備官方唯一支援的零衝擊持續增量入湖能力。
2. 內部團隊與 SI 廠商生態匹配：RSI 台北總部與海外各廠 IT 均深耕微軟技術棧（C# .NET Core, MS SQL AlwaysOn, Windows AD/Entra ID）。選擇 Azure 原生組合（APIM ＋ ADF ＋ ADLS Gen2），內部維運交接門檻最低、在台灣與東南亞更換 SI 維運廠商最容易，大幅降低 Bus Factor 單點人為黑數。
3. 外點 SD-WAN 離峰頻寬保護：各廠現場 MES / WMS 的 MS SQL 透過 Azure Data Factory (ADF) ＋ Self-hosted Integration Runtime (SHIR)，落實「外點深夜 01:00~03:00 離峰打包傳輸一次」，完全不擠壓日間車縫生產頻寬。
4. 開放格式防原廠鎖定：底層以 Parquet / Delta Lake 開放格式存放於 ADLS Gen2，未來若有跨雲需求，資料資產 100% 可攜，達成「維運管理集中、資料主權自主」。

驗收檢核項目 具體驗收標準 (Acceptance Criteria) 技術移轉檢核方式 (Proof of Handover)
1. 結算資料對帳零差異 連續 10 個工作日，D365 財務訂單數據與海外廠工單結算數值，在 ADLS Gen2 Gold 層對帳差異筆數為 0。 出具自動對帳比對報表，未解釋差異嚴格為零，並經財務與業務 Owner 簽核。
2. 跨國海纜斷線補跑驗證 模擬海外工廠斷線 4~8 小時，車間現場 MES 正常運作不卡死；復網後 30 分鐘內自動批次補傳追平，不漏單且無重複。 現場拔除外網實體線路進行實兵演練，驗證 Edge Proxy 降級與自動追平機制。
3. SD-WAN 頻寬保護實測 白天產線尖峰 (07:00~19:00) 跨國資料傳輸使用率增加 ≤ 5%；深夜 01:00~03:00 離峰傳輸於限定窗口內平穩結束。 調閱 Fortinet SD-WAN 流量監控曲線圖，確認日間生產通訊與視訊 100% 順暢。
4. 既有聯銓 BI 直連驗收 既有「聯銓 Smart eVision」戰情室報表無縫改由湖倉 Gold 層取數，清晨 06:00 開檔速度 ≤ 3 秒，指標完全一致。 海外各廠廠長開檔實測，清晨晨會生產數據無延遲出爐。
5. 可重複部署 (IaC) 移交 廠商必須交付完整 Bicep / Terraform 基礎設施腳本，不得包含任何私有黑箱代碼或廠商私人帳號綁定。 由 RSI 內部 IT 工程師於全新乾淨的測試訂閱環境中，執行腳本在 2 小時內 100% 重建整套環境。
6. 維運 Runbook 實兵排障 交付標準維運排障手冊（包含 SHIR 憑證輪更、Pipeline 失敗重跑、API 限流閥值調整、權限撤銷）。 由 RSI 內部工程師依據手冊獨立完成 3 項模擬故障排查演練，無需廠商人員在旁介入。
7. 分項成本與帳單可辨識 Azure 帳單必須明確依據 Resource Tag 分拆：APIM、ADF 執行時間、ADLS 儲存、網路出站與 D365 授權。 建立 Cost Management 預警閥值，單月預算超額即時自動發出 Teams / Email 告警。
