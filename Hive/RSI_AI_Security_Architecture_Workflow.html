為何對應 RSI 既有投資？

  • 無縫複用 Azure APIM：直接將既有業務整合閘道升級為「APIM＋MCP 治理閘道」，免重複採購與維運兩套介面。
  • 對齊蜂巢資料湖：RAG 僅讀取 ADLS Gen2／OneLake 清洗彙總層，落實「不直連 ERP 底層」鐵律。
  • 結合 Prisma SASE：200M 骨幹升級同步納管 12 據點 AI 流量，防堵 Shadow AI 資料外洩。

五大構面防禦重心

  • 流氓代理 (Rogue Agent)：透過 MCP Allowlist、短時效權杖與寫入 HITL 審批，杜絕代理越權執行。
  • 提示詞與 RAG 投毒：入口 AI Guardrails 過濾注入，檢索層以 Entra ID RBAC 嚴格切分廠區與公司別權限。
  • 供應鏈驗真 (AI-BOM)：鎖定官方模型與容器映像雜湊簽章，第三方 MCP Server 須經 ITS 資安審查上架。

四大 IT 組織清晰邊界

  • ITS：主責 Prisma SASE、AI 防火牆、GPU 基礎架構、SIEM 稽核與供應鏈掃描。
  • IS：主責 AI 代理開發、RAG 管道建置、Azure APIM＋MCP 閘道 Policy 與 MES API。
  • ERP Team & 各廠 IT：ERP Team 守護 D365 官方介面；各廠 IT 負責海外 8 廠地端設備與網路維運，不承擔開發。

01｜AI 代理
(AI Agents)		 業務詢價助理、跨廠排程建議、MES 異常判讀與報表代理 行為不當的流氓代理提示詞攻擊供應鏈 最小權限執行沙箱、單次任務呼叫上限（Rate/Budget Cap）、異常行為自動熔斷、代理版本納入程式碼審查 R：ISC：ITS / 各廠 IT
02｜大語言模型
(LLM)		 Azure OpenAI 企業專屬部署、統一 LLM Gateway（納管全部門與海外廠） LLM 攻擊／越獄提示詞攻擊供應鏈 Prisma SASE 封鎖未核准 Shadow AI、入口／出口 AI Guardrails、機密報價／BOM／個資自動 DLP 遮罩、零訓練資料留存條款 R：ITSC：IS
03｜RAG 管道
(RAG Pipeline)		 ADLS Gen2 / OneLake 彙總層知識庫（銜接 D365 Synapse Link 與 ADF 工廠資料） 提示詞攻擊（間接注入）供應鏈 Document-Level RBAC（依公司別／廠區動態過濾）、資料入庫前惡意指令與投毒掃描、僅允許唯讀存取彙總層 R：ISC：ERP Team / ITS
04｜GPU / AI 工廠
(AI Factory)		 Azure AI Foundry 託管算力、未來廠區地端視覺檢測／推論伺服器 供應鏈（權重／容器）LLM 推論攻擊 AI-BOM 模型雜湊簽章驗證、私有容器映像庫漏洞掃描、GPU 運算網段 VLAN 微分段隔離、算力異常使用監控 R：ITSC：IS / 各廠 IT
05｜MCP 閘道
(MCP Gateway)		 Azure APIM 擴充 MCP Governance Gateway（統一納管 D365 OData 與 MES API 工具） 流氓代理越權呼叫第三方 MCP 供應鏈 企業內部 MCP 工具白名單註冊表、短時效 OAuth 權杖、寫入型工具 100% 強制 HITL 人機審批、全量操作寫入 SIEM R：ISC：ERP Team / ITS
