📌 核心架構約束與戰略共識 (Architectural Directives)：
1. 現行微軟解決方案 (Microsoft Solution) 為穩健基底：信源地端核心 100% 採用 C# .NET Core / ASP.NET Web API 與 MS SQL Server (AlwaysOn AG)，任何公有雲或開源選型必須無縫對接微軟技術棧，絕不進行推倒重來的破壞性重構。
2. 外點結算一日一次傳輸 (保護 SD-WAN 頻寬)：海外三廠（越、柬、印尼）之成衣結算資料原則上一天傳輸一次（排定深夜 01:00 ~ 03:00 離峰時段），白天頻寬全力留給車間生產、視訊與 ERP 營運；重要特例（4-Gate 產前門禁、出貨核可）才由優先通道傳輸。
3. 海外三廠邊緣自律 (Edge Autonomy)：Edge Proxy ＋ 本地快取佇列，在國際海纜切斷時保障車間 48~72 小時連續離線生產，復網自動批次追平。
🏛️ 第一部分：API Platform 全域架構層級與工具選型對照矩陣
管理跨國即時交易、微軟 C# API 治理與邊緣離線自律
架構功能層級 1. Google Cloud (GCP) 方案 2. Amazon Web Services (AWS) 方案 3. OpenSource (開源自建) 方案
1. 邊界安全與流量防禦
(Security Edge & WAF)		 Cloud Armor + Cloud CDN
• 自動防禦 Layer 7 DDoS、SQL Injection 與 XSS。
• 設定海外三廠 IP 白名單與地理圍欄。
• 與 Cloud Load Balancing 深度整合。 		AWS WAF + CloudFront
• 託管 WAF 規則集 (Managed Rules)。
• Shield Advanced 提供跨國 DDoS 託管防禦。
• IP Set 配置海外廠與總部專用白名單。 		Coraza WAF + HAProxy / NGINX
• 基於 OWASP Core Rule Set (CRS) 深度防護。
• 部署於地端入口與 DMZ 隔離區。
• Fail2ban / CrowdSec 智慧 IP 封鎖。
2. API 閘道核心
(Enterprise API Gateway)		 Apigee X 或 Cloud API Gateway
• 企業級 API 治理、配額限制 (Quotas)。
• JWT Token 簽發驗證、OAuth 2.0 授權。
• OpenAPI (Swagger) 規範驗證與 Developer Portal。 		Amazon API Gateway
• 支援 REST API / HTTP API / WebSocket。
• 使用 Usage Plans 設定 API 速率與金鑰 (API Key)。
• 整合 Cognito 或 Windows AD 簽發 JWT Token。 		Kong Gateway (OSS) / Apache APISIX
• 業界標準高效能反向代理閘道。
• 外掛 (Plugins) 實作 Rate Limiting、CORS、JWT。
• 聲明式組態 (decK / YAML)，維護靈活。
3. 微服務執行運行環境
(Microservices Runtime)		 Cloud Run / GKE (K8s)
• 全託管 Serverless 容器，可縮容至 0 節省成本。
• 極速啟動執行 C# .NET 8 Web API 容器。
• 自動多區域流量分流與版本切換 (Blue-Green)。 		AWS ECS (Fargate) / EKS
• 無伺服器容器計算，無需管理 EC2 虛擬機。
• 深度支援 .NET Core 容器化應用。
• ALB (Application Load Balancer) 細緻路由分流。 		K3s (輕量 K8s) / Windows IIS 叢集
• 在本地 Dell/HP 伺服器自建輕量 Kubernetes。
• 或延續現有 Windows Server IIS 應用程式集區。
• 零雲端運算帳單，但需 SRE 團隊監控。
4. 海外三廠邊緣自律代理
(Edge Offline Autonomy)		 Google Distributed Cloud Edge
• 在廠端本地部署 Google 託管邊緣節點。
• 斷網時保持本地快取，復網自動同步狀態。 		AWS IoT Greengrass / ECS Anywhere
• 將 AWS 容器能力延伸至海外三廠工控機。
• 本地消息佇列暫存，斷網自律生產。 		Envoy Proxy + SQLite / Local Flat File
• 【信源推薦】極致輕量，在工控機部署 Envoy。
• 斷網自動回傳 202 Accepted，工單排入本地佇列。
• 海纜中斷維持 48~72hr 離線生產，復通自動批次平帳。
5. 全鏈路可觀測性
(Observability & APM)		 Cloud Trace + Cloud Logging
• 分散式鏈路追蹤，掌握跨國 API 調用延遲。
• 即時告警推播至 Teams IT 專用群組。 		AWS X-Ray + CloudWatch Logs
• 繪製服務地圖 (Service Map)，排查 API 調用死穴。
• CloudWatch Metrics 監控 4-Gate 產前門禁回應。 		OpenTelemetry + Jaeger + Prometheus/Grafana
• 業界中立無綁定標準，全面收集 C# .NET 指標。
• 在 Grafana 建立統一 IT 戰情大看板。
🌊 第二部分：Data Lakehouse ＆ ETL/ELT 數據平台架構與工具對照矩陣
管理 MS SQL 原生 CDC、外點離峰結算傳輸、湖倉三層與聯銓 BI
數據湖倉架構層級 1. Google Cloud (GCP) 方案 2. Amazon Web Services (AWS) 方案 3. OpenSource (開源自建) 方案
1. 地端數據源捕獲
(CDC Ingestion Layer)		 Google Datastream for BigQuery
• 原生讀取 MS SQL Server CDC 交易日誌。
• 無需在 SQL Server 安裝重型代理，零鎖表衝擊。
• 自動捕捉 Schema 變更並即時映射至湖倉。 		AWS DMS (Database Migration)
• 讀取 MS SQL Server CDC 交易日誌。
• 增量持續複製 (Ongoing Replication) 至 S3。
• 需配置 DMS Replication Instance 資源。 		Debezium (Kafka Connect)
• 業界最強開源 CDC 引擎，官方支援 SQL Server。
• 解析 SQL Server CDC 捕獲日誌為 JSON 事件流。
• 拋轉至 Apache Kafka / Redpanda 消息中樞。
2. 外點結算離峰傳輸
(SD-WAN 頻寬保護)		 Storage Transfer Service / gsutil
• 【排定深夜 01:00~03:00】外點一天傳一次。
• Zstandard/Gzip 高比率壓縮，頻寬佔用減 80%。
• 重大特例通道觸發高優先即時傳輸。 		AWS DataSync
• 排程排程任務於離峰 01:00 啟動。
• 差分增量傳輸至 S3，內建傳輸排程限速保護。
• 遇到 4-Gate 結關等重大特例可手動/API 立即喚醒。 		Rsync over SSH / Rclone + Zstd
• 使用 Linux/Windows 排程在深夜 01:00 執行。
• 本地打包切帳檔案，壓縮後推送至總部。
• 徹底保護跨國 SD-WAN 白天生產與視訊頻寬。
3. 現代湖倉儲存層
(Lakehouse Storage)		 Google Cloud Storage (GCS) + BigQuery
• Medallion 3 層架構 (Bronze/Silver/Gold)。
• 支援 Apache Iceberg 格式 (BigLake)。
• 支援 Time Travel (歷史快照回溯查詢) 與 ACID。 		Amazon S3 + Apache Iceberg on Athena
• S3 存放 Parquet 格式原始與清洗數據。
• Iceberg 提供 ACID 交易、行級變更與 Schema 演進。
• S3 Intelligent-Tiering 自動沉降歷史冷資料降成本。 		MinIO (S3 相容) + Apache Iceberg
• 地端私有雲物件儲存，完全相容 S3 API。
• 採用 Parquet + Iceberg 檔案格式。
• 數據 100% 保存在信源自有機房，無雲端儲存費用。
4. 數據轉換與清洗計算
(ETL / ELT Engine)		 BigQuery SQL (ELT) + dbt (Dataform)
• 【現代 ELT 典範】直接以 BigQuery 算力執行。
• 撰寫 MERGE 語法執行多廠工單對帳與 Upsert。
• dbt 進行資料模型版本控制與自動化測試。 		AWS Glue (Spark ETL) + dbt-core
• 無伺服器 Apache Spark 執行複雜資料轉換。
• 產出成衣產線平衡率、OEE、直通良率 (FTY)。
• 使用 Amazon Athena 進行即時互動式 SQL 查詢。 		Apache Spark / DuckDB + dbt-core
• Spark 處理跨廠巨量資料批次處理。
• DuckDB 單機極速分析每日結算總表。
• 依賴地端主機 CPU/RAM 資源，維護較繁瑣。
5. 全域排程調度中樞
(Data Orchestration)		 Google Cloud Composer
• 全託管 Apache Airflow 服務，免維護底層 K8s。
• 內建 GCP 連接器，輕鬆排定 Python DAG 工作流。
• 01:00 接收 ➔ 03:00 清洗 ➔ 06:00 派送報表。 		Amazon MWAA (Managed Airflow)
• AWS 全託管 Airflow 環境，安全整合 IAM。
• 自動依照任務排程負載動態擴展 Worker 數量。
• 失敗自動重跑 3 次並推播警報至 Teams。 		Apache Airflow (OSS)
• 自建於地端 Docker 容器或 Linux 虛擬機。
• 功能與雲端託管完全一致，程式碼 100% 共通。
• 需自行維護 PostgreSQL 後端資料庫與 Redis 佇列。
6. 商業智慧與消費層
(BI & Visualization)		 Looker + 聯銓 Smart eVision / Power BI
• 雙軌協同：聯銓 BI 負責廠長生產戰情，Power BI 負責跨國管理。
• BigQuery BI Engine 記憶體快取秒級加速。
• 支援對接 Gemini 模型執行語義數據問答。 		Amazon QuickSight + Power BI
• QuickSight SPICE 記憶體引擎加速查詢。
• 支援自然語言問答 (QuickSight Q)。
• 地端資料閘道 (Gateway) 連接 MS SQL 與 S3。 		Apache Superset / 聯銓 Smart eVision
• 延續信源現有 聯銓 Smart eVision 報表系統。
• 搭配開源 Apache Superset 提供現代切片看板。
• 每日清晨 06:00 自動產出 PDF/Excel 派送主管信箱。
🌐 Google Cloud (GCP) 蜂巢架構藍圖：極致分析能效 ＆ 湖倉一體
現代大數據分析首選

⚡ API Platform: Cloud Armor + Apigee + Cloud Run

1. 外部請求經由 Cloud Armor WAF 阻擋異常威脅，設定海外廠 IP 白名單。
2. Apigee X 負責企業級 API 契約治理、JWT 鑑權與速率限制。
3. Cloud Run 託管微軟 C# .NET 8 Web API 容器，按需自動擴展至數百執行個體。
4. 經由 Cloud VPN / 互連直通地端 MS SQL Server AlwaysOn 資料庫。

🌊 Data Lakehouse: Datastream + GCS + BigQuery

1. Datastream 透過非侵入式方式讀取地端 MS SQL Server CDC 交易日誌。
2. 外點結算一日一次（深夜 01:00~03:00）透過 Storage Transfer 離峰傳輸，保護 SD-WAN。
3. 數據寫入 GCS Apache Iceberg 格式，BigQuery 進行無伺服器 ELT 清洗。
4. Cloud Composer (Airflow) 自動編排，06:00 產出報表並推播。

💡 GCP 方案在信源全球之核心優勢：
• 分析體驗第一：BigQuery 是公有雲中維護負擔最低的湖倉，無需調校叢集大小、無伺服器架構立竿見影。
• 微軟 SQL Server 深度整合：Datastream 對 SQL Server CDC 支援極佳，增量管線建置僅需數小時。
• 潛在考量：Google Cloud 在越南與柬埔寨無本地機房（需連線至新加坡或台灣 Region），需依賴穩定 SD-WAN 線路。
☁️ Amazon Web Services (AWS) 蜂巢架構藍圖：全球覆蓋 ＆ 完整製造生態
全球節點覆蓋最廣

🛡️ API Platform: AWS WAF + API Gateway + ECS Fargate

1. AWS WAF + CloudFront 提供全球邊界加速與 Layer 7 防禦。
2. Amazon API Gateway 處理 RESTful 路由、Usage Plan 與 API Key 金鑰配額。
3. ECS Fargate 無伺服器架構運行 C# .NET Core 服務容器，彈性極佳。
4. 透過 AWS Direct Connect / Site-to-Site VPN 連接地端核心資料庫。

📦 Data Lakehouse: AWS DMS + S3 + Iceberg + Glue + Athena

1. AWS DMS 監聽地端 SQL Server CDC，持續捕捉成衣工單異動。
2. AWS DataSync 於每日深夜 01:00 離峰批次同步外點數據，嚴格限制頻寬。
3. Amazon S3 構建 Bronze/Silver/Gold 湖倉，採用 Apache Iceberg 格式。
4. AWS Glue (Spark) 執行批次清洗，Amazon Athena 支援無伺服器 SQL 查詢。

💡 AWS 方案在信源全球之核心優勢：
• 全球網路覆蓋最佳：AWS 在東南亞節點最齊全（新加坡、雅加達），連線延遲表現優異。
• 開源生態最繁榮：S3 ＋ Iceberg 幾乎是全球數據湖標準，未來遷移或切換成本最低。
• 潛在考量：AWS 計費項目極繁雜（Glue DPU、DMS 實例、NAT Gateway、數據外傳費），維護配置門檻較高。
🐧 OpenSource (自建開源) 蜂巢架構藍圖：極致自主可控 ＆ 零公有雲訂閱費
100% 機密自主可控

🚪 API Platform: Coraza WAF + Kong OSS + K3s / IIS

1. Coraza WAF + NGINX 自建入口邊界，加載 OWASP 安全規則集。
2. Kong Gateway (OSS) 或 Apache APISIX 部署於內部 Linux 節點。
3. C# .NET 應用部署於地端 K3s 容器叢集 或延續現有 Windows Server IIS。
4. 海外三廠工控機運行 Envoy Proxy ＋ SQLite 佇列，實現 48~72hr 離線自律。

🗄️ Data Lakehouse: Debezium + MinIO + Iceberg + Spark + Airflow

1. Debezium (Kafka Connect) 部署於地端，非侵入式讀取 SQL Server CDC。
2. Rsync / Rclone (Zstd 壓縮) 於每日深夜 01:00 執行跨廠離峰同步。
3. MinIO 提供 S3 相容之私有物件儲存池，結合 Apache Iceberg 儲存 Parquet。
4. Apache Airflow 自建版 排程排定 Spark/DuckDB 清洗，數據推送至 聯銓 Smart eVision。

💡 OpenSource 方案在信源全球之核心優勢：
• 零雲端授權費：完全無需支付公有雲的月度帳單，充分利用既有 Dell/HP 伺服器與硬體設備。
• 數據 100% 在地化：成衣製程版型、報價單與財務數據完全不離開信源內部機房，合規風險為零。
• 重大挑戰：維運負擔極重！需資深 SRE 團隊監控 Kafka 叢集、Spark 記憶體溢出與 K3s 節點狀態，且東南亞廠區較難招聘高級開源 SRE 工程師。

💡 Howard Liao Ph.D. 外部顧問之「信源全球最優解：混血漸進式落地方案」

基於信源全球「現今皆為 Microsoft Solution」與「外點一天傳一次保護 SD-WAN 頻寬」之實務現實，最穩健、成本最低且成效最快的落地策略為：

1. 地端核心不動搖 (AS-IS 根基)：台北總部與海外三廠維持 MS SQL Server AlwaysOn 與 C# .NET Core Web API，既有 聯銓 Smart eVision 繼續負責各廠廠長清晨生產晨會報表。
2. 數據中台採用 GCP BigQuery (TO-BE 現代化)：啟用 MS SQL 原生 CDC，透過排程於 每日深夜 01:00~03:00 離峰時段 打包傳輸至 Google BigQuery 建立湖倉，由周副總與管理層以 Microsoft Power BI 直連進行跨國經營分析。
3. 海外三廠採用 OpenSource Envoy 自律邊緣：海外三廠以最輕量的開源 Envoy Proxy ＋ SQLite 部署於工控主機，零授權費實現 48~72 小時離線生產保障，兼具極致穩定與成本效益！
