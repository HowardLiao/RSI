📌 核心架構約束與戰略基石 (Architectural Directives)：
1. 地端微軟解決方案 (Microsoft Solution) 為主力：台北總部與海外三廠維持 C# .NET Core Web API、MS SQL Server AlwaysOn 高可用叢集 與 聯銓 Smart eVision 晨會報表。
2. 外點結算一日一次傳輸 (保護 SD-WAN 頻寬)：海外三廠成衣工單資料原則上一天傳輸一次（排定深夜 01:00 ~ 03:00 離峰），杜絕白天佔用頻寬影響車間；重大特例通道啟動高優先即時傳輸。
3. 海外三廠邊緣自律 (Edge Autonomy)：Edge Proxy ＋ 本地快取，在國際海纜切斷時保障車間 48~72 小時連續離線生產，復網批次自動追平。
🏛️ 1.1 GCP 體系 · API Platform 架構層級圖與使用工具
Google Cloud Platform
🛡️ 邊界安全：Google Cloud Armor
Layer 7 WAF 防禦，防禦 SQL Injection / XSS，鎖定海外廠 IP 白名單，整合 Cloud CDN。
🚪 閘道核心：Apigee X / Cloud API Gateway
企業級契約治理，JWT Token 簽發驗證、Rate Limiting 限流、Swagger 規範自動校驗。
⚡ 運算託管：Cloud Run (.NET 8 容器)
無伺服器容器秒級擴展，運行 C# .NET Core Web API 核心微服務，無流量縮容至 0 節省成本。
🏭 邊緣自律：GDC Edge Proxy + 本地快取
海外三廠輕量代理，海纜切斷回傳 202 Accepted，車間連續 48~72hr 離線生產，復網自動補傳。

🌊 1.2 GCP 體系 · Data Lakehouse Platform + ETL/ELT 架構層級圖與使用工具
Google Cloud Platform
📥 增量捕獲：Google Datastream (CDC)
無伺服器 CDC，原生讀取 MS SQL Server 交易日誌，不鎖表、零衝擊捕捉成衣工單異動。
📡 離峰傳輸：Storage Transfer Service
【外點一日一次】排定深夜 01:00~03:00 離峰打包傳輸，保護 SD-WAN 白天頻寬；特例即時拋轉。

Medallion 3 層架構 (Bronze 原始 / Silver 清洗 / Gold 切帳總表)，支援 Apache Iceberg。
⏱️ 工作流編排：Google Cloud Composer (Airflow)
全託管 Airflow，每日排程：01:00 接收 ➔ 03:00 清洗 ➔ 05:00 聚合 ➔ 06:00 派送主管晨會報表。

🏛️ 2.1 AWS 體系 · API Platform 架構層級圖與使用工具

🛡️ 邊界安全：AWS WAF + CloudFront

Serverless 容器運算，託管 C# .NET Core 服務容器，ALB 負載平衡器分流。
🏭 邊緣自律：AWS IoT Greengrass / ECS Anywhere
本地延伸容器與訊息佇列，海纜中斷時車間維持 48~72hr 離線生產，復網自動補傳。

🌊 2.2 AWS 體系 · Data Lakehouse Platform + ETL/ELT 架構層級圖與使用工具
Amazon Web Services
📥 增量捕獲：AWS DMS (CDC)
讀取 MS SQL Server CDC 交易日誌，持續增量複製 (Ongoing Replication) 至 S3。
📡 離峰傳輸：AWS DataSync
【外點一日一次】排定深夜 01:00~03:00 離峰排程傳輸，具備帶寬限制 (Bandwidth Limit)。
🗄️ 湖倉儲存：Amazon S3 + Apache Iceberg
Bronze/Silver/Gold 3 層，Iceberg 提供 ACID 事務保證與 Time Travel 歷史回溯。
⚡ 批次計算：AWS Glue (Spark) + Athena
無伺服器 Spark ETL 執行資料清洗與指標聚合，Athena 執行即時 SQL 查詢。

🏛️ 3.1 OpenSource (自建開源) 體系 · API Platform 架構層級圖與使用工具

🏭 邊緣自律：Envoy Proxy + SQLite / Flat File
【極致輕量推薦】海外三廠工控機運行 Envoy，海纜中斷暫存本機，48~72hr 離線生產。

🌊 3.2 OpenSource (自建開源) 體系 · Data Lakehouse Platform + ETL/ELT 架構層級圖與使用工具

自建 Apache Airflow 編排 Spark/DuckDB 清洗，數據推送至 聯銓 Smart eVision 晨會。

💡 信源全球「漸進混血式」最佳落地藍圖 (Howard Liao Ph.D. 外部顧問決策建議)

1. 地端穩健根基：維持 100% Microsoft Solution（C# .NET Core Web API ＋ MS SQL Server AlwaysOn），既有「聯銓 Smart eVision」繼續負責各廠廠長清晨生產晨會報表。
2. 數據湖倉採 GCP BigQuery 體系：啟用 MS SQL 原生 CDC，排定【深夜 01:00~03:00】外點一日一次傳輸，零維護負擔建構 Medallion 3 層湖倉，周副總與管理層以 Microsoft Power BI 直連進行跨國經營分析。
3. 海外三廠採 OpenSource Envoy 邊緣自律：海外三廠工控主機部署開源 Envoy Proxy ＋ SQLite，零授權費達成 48~72 小時斷網自律生產保障！
