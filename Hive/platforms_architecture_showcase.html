🏛️ 微軟技術棧核心基底 (Microsoft Solution)

地端維持 C# .NET Core Web API、MS SQL Server AlwaysOn 高可用群組 與 Windows Server AD 網域，非侵入式現代化升級，保障生產營運韌性。

📡 SD-WAN 頻寬保護與離峰傳輸原則

外點成衣結算資料原則上一天傳輸一次（排定深夜 01:00~03:00 離峰），徹底杜絕白天產線搶頻寬；重大特例（4-Gate、出貨檢驗）才啟動高優先級多次即時通道。

🏭 海外各產區邊緣自律 (Edge Autonomy)

越南、柬埔寨、印尼、孟加拉配置 Edge Proxy ＋ 本地快取，國際海纜切斷時，車間現場維持 48~72 小時連續離線生產，復網批次自動追平。

Draw.io 向量格式 · 涵蓋安全邊界、API Gateway、微軟 C# .NET 中台、邊緣代理與湖倉介接
💡 API Platform 架構設計關鍵特色：
1. 安全防線與身分驗證：Cloud Armor / WAF 杜絕外部惡意攻擊；API Gateway 實作 JWT Token 簽發、OAuth2 授權與海外廠 IP 白名單過濾。
2. 微軟 C# .NET 核心微服務：包含「成衣 ERP 訂單服務」、「車間 MES 計件服務」、「4-Gate 產前門禁防呆服務」與「WMS 倉儲物流服務」，與 MS SQL Server 叢集直連。
3. 海外各產區邊緣自律 (Edge Resilience)：各廠 Edge Proxy 監聽海纜狀態，斷網自動暫存並回傳 HTTP 202 Accepted，復網無感補傳。
⏱️ 時序 1：RSI Group API Platform 端到端調用與離線自律時序圖
展示車間正常呼叫、海纜中斷邊緣快取、國際連線復原自動補傳之全生命週期
💡 時序調用流程解析：
• 情境 A (正常連線)：車間刷槍 ➔ 海外 Edge Proxy ➔ 跨國 SD-WAN ➔ API Gateway (鑑權+Rate Limit) ➔ C# .NET Core 後端 ➔ MS SQL Server (AlwaysOn 寫入) ➔ 毫秒級回傳 200 OK。
• 情境 B (海纜中斷離線生產)：Edge Proxy 偵測連線逾時，立即切換為本地 SQLite 佇列暫存，向車間機台回傳 202 Accepted，工廠連續生產 48~72 小時不中斷。
• 情境 C (復網自動同步)：心跳偵測復通，Edge Proxy 自動批次壓縮補傳增量工單數據，總部中台平帳並記錄審計日誌。
🌊 架構 2：RSI Group Data Lakehouse Platform & ETL/ELT 5 層數據架構圖
Draw.io 向量格式 · 涵蓋外點 SD-WAN 頻寬保護、Bronze/Silver/Gold 3 層湖倉、Airflow 與聯銓 BI
💡 Data Lakehouse 數據平台架構設計關鍵特色：
1. 外點結算一天一次傳輸 (Daily Off-Peak Batch)：為保障白天 SD-WAN 頻寬供產線與視訊使用，海外各產區結算資料於每日深夜離峰時段（01:00 ~ 03:00）打包壓縮傳輸一次。
2. 重大特例通道 (Priority On-Demand Trigger)：遇 4-Gate 結關、大貨出貨檢驗或重大異常，啟動高優先即時傳輸。
3. Medallion 3 層湖倉：Bronze (原始事件) ➔ Silver (資料清洗對齊) ➔ Gold (切帳總表直連聯銓 BI 與 Power BI)。
📊 時序 2：Data Lake 外點結算離峰傳輸與 BI 報表產出時序圖
展示白天本地快取 ➔ 深夜 01:00 離峰批次傳輸 ➔ 湖倉清洗 ➔ 清晨 06:00 派送報表全流程
💡 跨日夜數據生命週期流程：
• 白天營運時段 (08:00 ~ 20:00)：海外各產區車間工單資料僅寫入本地 MS SQL Server，不占用跨國 SD-WAN 頻寬。
• 深夜離峰結算 (01:00 ~ 03:00)：排程任務啟動，將前日結算資料打包壓縮，透過 SD-WAN 一日一次安全傳輸至台北數據中心。
• 湖倉排程清洗 (03:00 ~ 05:00)：Apache Airflow 排程觸發，依序執行 Bronze 寫入、Silver 去重對帳、Gold 跨廠指標聚合。
• 主管晨會報表 (06:00)：聯銓 Smart eVision 與 Microsoft Power BI 自動轉檔，派送前日跨國生產戰情至周副總與各廠廠長信箱。
