1. 軟體工程：前端與後端開發 (Software Engineering)
核心必填
涵蓋前端 UI 切版、後端 C#/.NET/Java/Python Web API、T-SQL 預存程序與死鎖調校。
Q1-1. 前端 UI 開發與響應式切版 (HTML5 / Vue / React / RWD)
能否熟練使用現代前端框架或原生 JS/CSS 開發手機/平板/電腦自適應的業務表單與看板？
Q1-2. 後端應用服務開發 (C# .NET Core / Java / Python Web API)
能否設計 RESTful API、處理依賴注入、交易事務控制 (Transaction) 並與 ERP/MES 後端介接？
Q1-3. 進階 T-SQL 撰寫、Stored Procedure 與死鎖調校
能否編寫複雜 CTE、窗口函數、優化執行計畫 (Execution Plan)、解決 SQL Server Deadlock 阻礙？
2. 實體硬體與車間設施 (Hardware & Shopfloor Equipment)
核心必填
涵蓋 Dell/HP 伺服器、RAID 磁碟陣列、NAS/SAN、VMware 虛擬化與車間工控機 (IPC)。
Q2-1. 機架伺服器硬體管理 (Dell R740 / HP DL380 / iDRAC)
能否獨立進行實體主機上架、硬體故障診斷、使用 iDRAC / iLO 帶外管理並更新韌體？
Q2-2. 磁碟陣列 RAID 配置、抽換重建與儲存 NAS 維護
能否配置 RAID 1/5/6/10、設定 Hot Spare 熱備援、抽換故障硬碟重建，並管理 Synology NAS 空間？
Q2-3. 車間工控機 (IPC) 與吊掛 RFID 讀寫器除錯
能否維護研華工控機、排查 COM 串列埠通訊、調整 Impinj RFID 天線角度並解決機台通訊異常？
3. 廠區網路架構與傳輸 (Network & Wi-Fi Infrastructure)
核心必填
涵蓋核心交換器、VLAN 切割隔離、車間 Wi-Fi 覆蓋調優與雙線路備援。
Q3-1. 核心交換器 (Core Switch) 設定、堆疊與鏈路聚合
能否維護 Cisco/Aruba 核心交換機、配置 LACP 聚合、規劃靜態/動態路由與預設閘道備援？
Q3-2. 廠區 VLAN 網段規劃、Trunk 與存取控制清單 (ACL)
能否規劃 VLAN 隔離車間機台、伺服器、辦公室與訪客網路，配置 802.1Q 埠並防止廣播風暴？
Q3-3. 車間企業級 Wi-Fi 覆蓋調優與死角消除
能否管理 Aruba/Unifi AP 控制器、調整無線射頻通道 (Channel)、優化車間條碼槍快速漫遊？
4. 公有雲與數據中台 (Cloud & Lakehouse Architecture)
核心必填
涵蓋 GCP/AWS 雲端環境操作、BigQuery 數據倉儲、Apache Airflow 排程與 FinOps。
Q4-1. 公有雲基礎架構操作 (GCP / AWS 控制台與 IAM)
能否在 GCP 或 AWS 控制台建立 VPC 子網、管理 VM 實例、配置 IAM 最小權限角色與安全群組？
Q4-2. 雲端現代數據倉儲 (Google BigQuery / S3 Iceberg)
能否在 BigQuery 建立分區表 (Partitioning)、撰寫 MERGE 語法執行對帳、並優化查詢掃描成本？
Q4-3. 工作流編排排程實務 (Apache Airflow DAG)
能否使用 Python 撰寫 Airflow DAG 腳本、設定任務前後依賴關係、配置失敗重跑與告警通知？
5. 資訊安全與存取防護 (Cybersecurity & SASE)
核心必填
涵蓋次世代防火牆 (Fortinet)、零信任存取 (ZTNA)、SaaS 影子IT控管 (CASB/DLP) 與防勒索 WORM。
Q5-1. 次世代防火牆 (FortiGate NGFW) 安全策略與 IPS
能否配置 Fortinet 防火牆安全策略 (Policies)、啟用防毒與 IPS 深度檢測並排除誤判？
Q5-2. 企業備份架構 (Veeam Backup 3-2-1 原則實務)
能否配置每日完整與差異備份、設定備份加密、並能獨立執行 VM 及資料庫之實體還原開機測試？
Q5-3. 防勒索不可篡改備份池 (WORM) 與 MFA 雙因子推行
是否理解並能配置不可篡改唯讀備份池，並推行 Authenticator 雙因子認證強制啟用？
6. 網站可靠性工程與維運 (SRE & DevOps)
核心必填
涵蓋系統可用性指標 (SLA/SLO)、日誌集中監控 (Prometheus/Grafana)、CI/CD 自動化與容器。
Q6-1. 服務等級目標與可用性監控 (SLI / SLO / SLA)
能否為關鍵成衣系統定義可用性指標（如 99.9% 正常運行時間）、計算錯誤預算 (Error Budget)？
Q6-2. 集中化日誌與效能監控 (Prometheus / Grafana / Zabbix)
能否建立集中監控儀表、收集伺服器 CPU/RAM/磁碟/API 回應時間、並設定閥值自動通報？
Q6-3. 容器化與 CI/CD 自動化發布觀念 (Docker / Git Pipeline)
能否看懂 Dockerfile、使用 docker-compose 運行多容器、或使用 GitHub Actions 執行自動化測試打包？
7. 資訊管理與終端維運 (MIS & IT Service Management)
核心必填
涵蓋 Active Directory 網域管理、GPO 派送、M365 租戶維護、軟體資產合規與使用者支援。
Q7-1. Active Directory 網域控制、GPO 安全原則與帳號審查
能否管理網域控制器 (DC)、規劃 OU 組織單位、使用 GPO 派送安全性設定並落實離職及時停權？
Q7-2. Microsoft 365 租戶管理 (Exchange / Teams / 授權盤點)
能否管理 M365 企業帳號、管理 Exchange 郵件流與安全性、排查員工授權閒置浪費？
Q7-3. 終端電腦映像檔大量部署 (Ghost/WDS) 與 ITIL 工單處理
能否製作標準化 Windows 系統映像檔大量派送、並依照 SLA 規範處理使用者 Helpdesk 工單？
8. 各點連線與 SD-WAN 協作 (Connectivity & SD-WAN)
核心必填
涵蓋跨國 VPN、SD-WAN 頻寬保護、外點一日一次離峰傳輸排程與海纜斷網離線自治。
Q8-1. 跨國 Site-to-Site IPSec VPN 建立與連線除錯
能否在 Fortinet 防火牆建立台北總部至海外三廠之 IPSec VPN 穿隧並排除網路抖動問題？
Q8-2. 外點結算一日一次傳輸排程 (深夜離峰 · SD-WAN 頻寬保護)
是否清楚落實：外點結算資料原則上一天傳輸一次（深夜 01:00~03:00 打包），避免白天影響頻寬？
Q8-3. 重大緊急特例多次傳輸通道 (4-Gate 結關 / 嚴重品質異常)
能否配置針對 4-Gate 產前門禁急需出貨結關時的高優先級即時多次傳輸通道？
