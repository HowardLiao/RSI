💡 架構設計特點：
1. 安全雙防線：Cloud Armor / WAF 防禦外部攻擊與海外廠 IP 白名單；核心 API 閘道執行嚴格 JWT 簽章與 Rate Limiting 限流。
2. 邊緣離線自治 (Edge Resilience)：海外各產區（越、柬、印、孟尼）配置輕量 Edge Proxy ＋ 本地持久化快取，海纜中斷時車間生產不受阻，復網自動批次追平。
3. 湖倉直通：API 與 Datastream/DMS CDC 管道緊密聯動，每小時增量匯入 BigQuery 核心數據中台。
⏱️ API Platform 端到端調用時序圖 (含海纜斷網離線自治與復網補傳機制)
Draw.io 格式 · 分步驟展示正常傳輸與異常容錯流程
💡 時序圖關鍵情境拆解：
• 場景一（正常連線）：車間 MES ➔ Edge Proxy ➔ 雲端 WAF ➔ API Gateway 鑑權 ➔ 寫入 BigQuery 湖倉 ➔ 回傳 HTTP 200 OK（全鏈路 15~35ms）。
• 場景二（海纜斷線離線自律）：對外逾時 ➔ Edge Proxy 自動降級寫入地端 SQLite 快取 ➔ 回傳 HTTP 202 Accepted ➔ 車間不停擺、機台不卡死。
• 場景三（復網批次追平）：守護程序偵測復網 ➔ 依序批次補傳 ➔ 寫入 BigQuery 補追庫 ➔ 告警通報完成。
