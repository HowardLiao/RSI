為精準掌握台北總部與海外三廠（越南隆安、柬埔寨金邊、印尼中爪哇）內部 IT 同仁的真實技術掌握度與系統維護現況，本問卷圍繞 1.軟體 2.硬體 3.網路 4.雲端 5.各點連線協作 6.資安 等 6 大維度設計。調查結果將作為 2027 蜂巢計畫技術培訓安排、跨廠職能矩陣分工及原廠資源引進之依據。本問卷非個人考績單一懲處，請同仁依「實際能夠獨立解決問題之經驗」如實作答。
熟練度評分 客觀等級標籤 具體行為表現標準 (請依此客觀作答)

5 分 · 架構專家 Expert / Lead 具備架構規劃、技術選型與高可用設計能力，能指導並帶教其他同仁。

Part 1. 軟體與應用系統 (Software & Applications)
評估同仁在核心 ERP/MES、MS SQL 資料庫維護、T-SQL 語法與聯銓 BI 報表之能力。
Q1-1. 核心 ERP / MES / WMS 業務系統維運能力
能否處理成衣 BOM 表展開、訂單拋轉、車縫工序計件回傳或外協工單之異常除錯？
Q1-2. Microsoft SQL Server 資料庫日常管理與維護
能否獨立執行資料庫安裝、配置定期備份排程、交易日誌截斷 (Truncate) 與實體資料庫災難還原？
Q1-3. 進階 T-SQL 撰寫與預存程序 (Stored Procedure) 開發
能否撰寫複雜多表 JOIN、通用資料表運算式 (CTE)、窗口函數 (Window Functions) 及交易事務控制 (BEGIN TRAN/COMMIT)？
Q1-4. 資料庫效能調優、索引設計與死鎖排查 (Deadlock)
能否判讀 Execution Plan 找出全表掃描效能盲點、設計包含資料欄索引 (Covering Index) 並解決鎖定阻礙？
Q1-5. 聯銓 Smart eVision 報表開發與 Excel VBA 巨集
能否在聯銓 BI 配置資料集、設計多維度交叉儀表板；或修改維護生管複雜 Excel 巨集程式碼？
Part 2. 硬體與伺服器機房設施 (Hardware & Equipment)
評估同仁在實體伺服器、RAID 陣列、VMware 虛擬化與車間工控機 (IPC) 之維護能力。
Q2-1. 機架伺服器硬體維護 (Dell PowerEdge / HP DL380)
能否獨立進行實體伺服器上架、硬體故障診斷、使用 iDRAC / iLO 帶外管理並進行韌體升級？
Q2-2. 磁碟陣列卡配置與抽換重建 (RAID 1/5/6/10)
能否配置 RAID 陣列卡、設定 Hot Spare 熱備援硬碟、並在硬碟亮黃燈故障時正確熱插拔抽換？
Q2-3. VMware ESXi 虛擬化平台維運與 vMotion
能否建立虛擬機、分配調整 vCPU/RAM/磁碟規格、配置 vSwitch 虛擬交換器並執行虛擬機熱遷移？
Q2-4. 車間工控電腦 (IPC) 與吊掛 RFID 讀寫器除錯
能否維護研華工控機、排查 COM 串列埠通訊、調整 Impinj RFID 讀寫器天線角度並解決漏讀異常？
Q2-5. 機房電力、在線式不斷電系統 (UPS) 與環境維護
能否執行 APC 機房 UPS 定期放電測試、確認電池健康狀態、管理空調溫濕度並測試發電機切換？
Part 3. 廠區網路架構與傳輸環境 (Network Infrastructure)
評估同仁在核心交換機、VLAN 劃分、車間 Wi-Fi 覆蓋與外網雙線備援之能力。
Q3-1. 核心交換器 (Core Switch) 設定與堆疊維護
能否維護 Cisco / Aruba 核心交換機、配置 LACP 鏈路聚合、設定靜態/動態路由與網關備援？
Q3-2. 廠區 VLAN 網段規劃、Trunk 與存取控制清單 (ACL)
能否規劃 VLAN 隔離車間機台、伺服器、辦公室與訪客網路，配置 802.1Q 埠並防止廣播風暴？
Q3-3. 車間企業級 Wi-Fi 覆蓋調優與信號死角排查
能否管理 Aruba / Unifi 無線 AP 控制器、調整無線射頻通道 (Channel)、優化車間條碼槍快速漫遊？
Q3-4. 廠區對外固網雙線路與 4G 備援 (Dual-WAN Failover)
能否設定雙電信商線路自動故障切換 (Failover)、配置 4G/5G 路由器備援通訊並進行演練？
Q3-5. 網路封包分析與斷線定位 (Wireshark / 網管監控)
能否使用 Wireshark 抓包分析 TCP 重傳、判讀連線逾時原因，並使用 SNMP/PRTG 監控頻寬流量？

Q4-1. 公有雲基礎架構與權限安全治理 (GCP / AWS IAM)

能否在 Fortinet 防火牆建立台北總部至海外三廠之 IPSec VPN 穿隧並排除斷線問題？
