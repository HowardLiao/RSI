# 信源全球 (RSI) · 蜂巢計畫 (Hive Project)
## 內部 IT 技術職能問卷同仁提交檔案歸檔庫 (Survey Submissions Repository)

本目錄專門用於集中記錄與歸檔台北營運總部及海外三廠（越南隆安、柬埔寨金邊、印尼中爪哇）內部 IT 同仁所填寫之《內部 IT 技術職能問卷》結構化數據（CSV 格式）。

---

### 一、檔名規範 (File Naming Standard)

依專案規範，每位同仁填表送出時，系統將自動生成標準命名之 CSV 檔案：

$$\text{【填寫日期時間】} + \text{【姓名】} + \text{【工號】} + \text{.csv}$$

- **格式範例**：`20261014_153020+陳志遠+RSI-92015+.csv`
  - **填寫日期時間**：`YYYYMMDD_HHMMSS`（年月日_時分秒，24小時制）
  - **姓名**：同仁中文或英文姓名（例：`陳志遠` 或 `EdwardChen`）
  - **工號**：公司標準工號（例：`RSI-92015`）
  - **結尾標記**：`+` 及副檔名 `.csv`

---

### 二、CSV 檔案內容結構說明

所有存檔之 CSV 檔案均採用標準 **UTF-8 with BOM** 編碼（確保 Excel 繁體中文無亂碼），內含三大層級：

1. **Part 0. 受評同仁基本資訊**（姓名、工號、廠區、主職能、兼任副職能、年資、直屬主管）
2. **主要技術職能專屬問卷 (10題)** ＆ **兼任副職能專屬問卷 (各10題)** 之題目代碼、題名、自評成熟度 (1~5分)、2027目標基準線 (Target) 與技術缺口 (Gap)
3. **單點脆弱度 (Bus Factor) 客觀排查**（職務代理人狀態、SOP完整度、衝擊等級、高風險系統代碼）

---

### 三、自動歸檔與匯整作業

- **線上填報端點**：https://howardliao.github.io/RSI/Hive/it_skills_8domains_assessment.html
- **自動化數據匯總**：專案推動小組定期執行匯總腳本，將本目錄下所有同仁的 CSV 數據彙整為集團《技術戰力總雷達矩陣》與《Bus Factor 單點黑數清冊》，呈報周副總經理核閱。
