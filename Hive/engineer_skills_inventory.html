L5 · 戰略導師 Master / Mentor 具備業界權威級認知，能制定全集團技術標準、資安規範，並規劃未來 3 年技術藍圖。

領域範疇 技術與技能項目 實務應用內容說明 自評等級 (L1 ~ L5)
1. 資料庫與
數據工程		 Microsoft SQL Server 維運 資料庫安裝、備份還原、AlwaysOn HA、權限設定與磁碟空間管理。
T-SQL 語法與預存程序 (SP) 能撰寫複雜 JOIN、預存程序、視圖 (View) 與業務邏輯觸發器 (Trigger)。
效能優化與 Index 調優 能看懂執行計畫 (Execution Plan)、排查死鎖 (Deadlock)、設計適當叢集索引。
異動捕獲 (CDC) 與排程 ETL 理解 SQL Server CDC / Change Tracking 原理，或有 SSIS 資料拋轉經驗。
2. 雲端與
現代數據架構		 公有雲基礎架構 (GCP / AWS) 理解 IAM 權限、VPC 網路、VM 實例配置與物件儲存 (S3 / GCS) 概念。
雲端數據倉儲 (BigQuery / Redshift) 曾使用過雲端 DWH 下 SQL、建立資料市集、理解資料分區與叢集原理。
工作流編排 (Apache Airflow) 能看懂或撰寫 Python Airflow DAG，配置工作依賴、排程與告警通道。
3. API 串接與
中台整合		 RESTful API 設計與呼叫 理解 HTTP 動詞、JSON 格式解析、狀態碼 (200/404/500) 與錯誤處理。
API 工具除錯 (Postman / Swagger) 能熟練使用 Postman 進行介面模擬測試、變數配置與自動化請求發送。
API 鑑權與安全 (JWT / OAuth2 / 金鑰) 理解 Token 認證機制、API 金鑰驗證、HTTPS 憑證配置與存取頻率限制。
4. 軟體開發與
指令碼維運		 自動化指令碼 (PowerShell / Python / Bash) 能撰寫指令碼執行排程備份、文字清洗、自動告警推播或檔案同步。
應用軟體開發 (C# .NET / Java 等) 能閱讀或維護既有 ERP/MES 之後端程式碼，開發客製化業務小模組。
版控與容器 (Git / Docker 基礎) 具備 Git 程式碼 commit/push/branch 觀念，或能使用 Docker 啟動服務。
5. 報表開發與
商業智慧		 聯銓 BI 報表系統開發 熟悉聯銓 BI 資料集設定、維度切片、多維儀表板設計與權限發布。
現代 BI 工具 (Power BI / Excel VBA 巨集) 能使用 Power BI 建構數據模型，或維護生管複雜 Excel 巨集試算表。
6. 基礎設施、
網路與車間 OT		 Windows Server ＆ Active Directory (AD) 網域管理、帳號生命週期、群組原則 (GPO)、DNS/DHCP 與檔案共用。
虛擬化平台 (VMware ESXi / vCenter) 虛擬機建立、資源配額配置、快照 (Snapshot) 管理與主機負載監控。
跨國廠區網路與防火牆 (VPN / VLAN) 實體交換器切割 VLAN、Fortinet 防火牆規則設定、Site-to-Site VPN 除錯。
車間設備與 OT 機台連網 (RFID / 裁床) 自動拉布裁床、吊掛系統 RFID 讀寫器、工控機 (IPC) 通訊介面連線排除。
7. 資訊安全與
備份災變復原		 備份機制與災難復原演練 (Veeam / 異地備份) 熟悉 3-2-1 備份原則，能執行定期資料庫還原驗證，理解 RTO/RPO 規範。
資安防護與端點應變 (EDR / 防毒 / 勒索防護) 能排查惡意軟體警報、執行主機安全性修補，遵循最小權限帳號原則。
