二、8 大核心領域技術實務評鑑矩陣 (8 Domains Granular Competency Matrix)
核心領域 具體實務技術項目 實務檢核標準與具體行為驗證指標 (Checklist) 熟練度自評 (L1 ~ L5)
1. 軟體工程
(前端、後端)
[DEV & DB]		 前端 UI 開發與 RWD 切版 熟練 HTML5/CSS3/JavaScript，能使用 Vue/React 或原生框架開發自適應跨裝置（手機/平板/工控機）業務表單與即時戰情看板。
後端 Web API 與服務開發 熟練 C# .NET Core / Java / Python 開發 RESTful API，能處理依賴注入、交易事務控制 (Transaction)、批次排程與成衣工序回傳介接。
進階 T-SQL 與 Stored Procedure 精通多表 JOIN、通用資料表運算式 (CTE)、窗口函數 (Window Functions)、撰寫複雜預存程序 (SP) 與成衣 BOM 展開邏輯。
聯銓 Smart eVision 報表開發 熟悉聯銓 BI 資料集設定、SQL 查詢優化、多維度交叉分析設計、圖表佈局與條件式格式化，具備報表排程派送經驗。
2. 實體硬體與設施
[HARDWARE]		 機架伺服器與 iDRAC 帶外維運 Dell PowerEdge R740 / HP DL380 實體伺服器上架、硬體故障診斷、使用 iDRAC/iLO 帶外管理、配置熱備援電源與更新微碼韌體。
磁碟陣列卡 RAID 與儲存管理 配置 RAID 1/5/6/10 陣列、設定 Hot Spare 熱備援硬碟、熱插拔抽換故障硬碟並執行在線重建 (Rebuild)，維護 NAS 儲存池。
車間工控機 (IPC) 與 RFID 設備 研華工控機除塵維護、RS-232/COM 串列通訊排查、Impinj 吊掛 RFID 讀寫器天線增益與角度校正，排查漏讀通訊異常。
3. 廠區網路傳輸
[NETWORK]		 核心交換器與 VLAN 隔離規劃 Cisco/Aruba 核心交換機維護、配置 LACP 鏈路聚合、規劃 802.1Q VLAN 隔離車間/伺服器/辦公網段，配置靜態路由與廣播風暴抑制。
車間企業級 Wi-Fi 覆蓋調優 Aruba/Unifi AP 控制器管理、射頻通道 (Channel) 規劃避開干擾、調校車間條碼槍快速漫遊 (802.11r/k/v)，排除生產死角。
雙線路 Dual-WAN 與 4G 備援 配置雙電信商外網線路自動故障切換 (Failover)、配置 4G/5G 路由器緊急備援通道，並使用 Wireshark 抓包分析連線延遲問題。
4. 公有雲與數據中台
[CLOUD & LAKE]		 公有雲架構與安全治理 (GCP/AWS) VPC 子網劃分、VM 實例生命週期、IAM 最小權限角色分配、服務帳號 (Service Account) 金鑰管理與雲端費用預算預警。
現代數據倉儲 (Google BigQuery) 建立時間分區表 (Partitioning) 與叢集表 (Clustering)、撰寫 MERGE 語法執行 Upsert 對帳、BI Engine 快取加速、查詢掃描成本優化。
工作流編排 (Apache Airflow DAG) 使用 Python 撰寫 Airflow DAG 腳本、配置 Task 依賴關係、排定 Cron 排程、配置失敗自動重跑與 Teams/Email 告警。
5. 資訊安全與存取防護
[SECURITY & SASE]		 次世代防火牆 (NGFW) 與邊界策略 熟練配置 Fortinet 防火牆存取策略 (Policies)、位址物件、NAT 埠轉發、啟用防毒與 IPS 深度檢測並排除系統誤判。
零信任存取與免安裝架構 (ZTNA) 落實依身分與最小權限限制內部應用存取（非直接開放全內網）；理解外包商免安裝 (Clientless Portal / 企業安全瀏覽器) 存取機制。
SaaS 治理、資料防洩與安全上網
(CASB + DLP + SWG)		 掌握雲端應用與影子 IT 控管 (CASB)、配置機密資料外洩防護 (DLP 內容檢測)、安全網頁閘道 (SWG 惡意網頁威脅過濾)。
Veeam 3-2-1 備份與防勒索不可篡改 (WORM) 配置每日完整與差異備份、設定備份加密金鑰、配置防勒索不可篡改備份池 (Immutable / WORM)，並定期執行 VM 實體開機還原測試。
6. 網站可靠性工程
[SRE & DEVOPS]		 可用性指標定義 (SLI / SLO / SLA) 能為關鍵成衣系統定義可用性指標（如 99.9% 正常運行時間）、計算錯誤預算 (Error Budget) 並建立故障自動升級反應機制。
集中化監控與告警 (Prometheus/Grafana) 建立統一監控面板、收集伺服器 CPU/RAM/磁碟/API 回應時間、配置閥值自動發送警報至 Teams/LINE，排除被動救火。
容器化技術與 CI/CD 流程觀念 (Docker) 看懂與撰寫 Dockerfile、使用 docker-compose 運行多容器、使用 Git 分支管理代碼、理解 GitHub Actions 自動化打包發布。
7. 資訊管理與維運
[MIS & ITSM]		 Active Directory 網域控制與 GPO 管理網域控制器 (DC)、規劃 OU 組織單位、使用 GPO 派送安全性設定、定期執行特權帳號審查並落實員工離職即時停權。
Microsoft 365 租戶與郵件流治理 管理 M365 企業帳號、管理 Exchange 郵件流與反垃圾郵件安全、排查員工授權閒置浪費，落實 MFA 雙因子認證。
標準系統映像檔大量部署 (Ghost/WDS) 製作標準化 Windows 系統映像檔大量派送、IT 資產生命週期管理、依照 SLA 處理使用者 Helpdesk 支援工單。
8. 各點連線與 SD-WAN
[CONNECTIVITY]		 跨國 Site-to-Site VPN ＆ SD-WAN 實務 建立與維護台北總部至海外三廠之 IPSec VPN 穿隧、監控跨國海纜延遲 (Ping RTT/Jitter)、設定 SD-WAN 流量智慧選路與 QoS 頻寬優先級。
外點結算一日一次傳輸 (離峰 SD-WAN 保護) 嚴格落實外點結算排程「一天傳輸一次（深夜 01:00~03:00 離峰打包）」，保護 SD-WAN 頻寬不被大數據癱瘓；重大緊急事件（4-Gate 出貨結關/品質異常）始走專屬特例通道。
邊緣離線自治與快取佇列 (48~72hr 保障) 配置現場機台或 Edge Proxy 的本地快取佇列 (SQLite/平坦檔)，國際海纜中斷時確保車間離線正常生產，連線復原後自動批次追平。
