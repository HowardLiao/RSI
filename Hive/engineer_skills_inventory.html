1. 資料庫與
數據工程
(Database & Data) 		MS SQL 基礎維運與備份還原 資料庫安裝配置、資料表維護、定期完整/差異備份、交易日誌截斷 (Truncate) 與災難還原實作。
高可用與叢集架構 (AlwaysOn) 配置與維護 AlwaysOn 可用性群組 (AG)、故障移轉叢集 (Failover Cluster)、資料庫記錄傳送 (Log Shipping)。
進階 T-SQL 撰寫與 Stored Procedure 精通多表 JOIN、通用資料表運算式 (CTE)、窗口函數 (Window Functions)、複雜預存程序 (SP) 與交易控制 (BEGIN TRAN/COMMIT)。
索引架構設計與碎片調校 設計叢集 (Clustered) 與非叢集索引、包含資料欄索引 (Covering Index)、篩選索引 (Filtered Index)，執行定期 Index Reorganize/Rebuild。
效能診斷與死鎖排查 (Deadlock/Plan) 能判讀執行計畫 (Execution Plan) 找出 Index Scan 效能盲點、使用 Extended Events (擴充事件) 抓取 Deadlock 阻礙並解決鎖定問題。
資料異動捕獲 (CDC / Change Tracking) 理解 SQL Server 原生 CDC 啟用機制、日誌保留天數配置、變更捕獲清理作業 (sys.sp_cdc_cleanup_change_table) 與 SSIS 拋轉。
2. 雲端與
現代數據湖倉
(Cloud & Lakehouse) 		公有雲架構與安全治理 (GCP / AWS) IAM 最小權限角色配置、VPC 專用網路與子網規劃、金鑰管理 (KMS)、服務帳戶 (Service Account) 與雲端費用預警。
物件儲存與生命週期 (GCS / S3) 儲存貯體 (Bucket) 權限、版本控制、分層儲存 (Standard/Nearline/Coldline/Archive) 與自動生命週期沉降政策 (Lifecycle Policy)。
雲端數據倉儲 (BigQuery / Redshift) 建立分區表 (Partitioning) 與叢集 (Clustering)、撰寫 MERGE 語法執行 Upsert、BI Engine 快取加速配置、查詢掃描成本優化。
現代 Lakehouse 表格格式 (Apache Iceberg) 理解 ACID 交易機制、Schema 演進、隱式分區、Time Travel (歷史快照回溯查詢) 與檔案自動壓實 (Compaction)。
工作流編排 (Apache Airflow / Composer) 使用 Python 撰寫 Airflow DAG、使用 BashOperator / PythonOperator、配置 Task 依賴關係、排定 Cron 排程、配置 Slack/Teams 失敗告警。
3. API 平台與
中台系統整合
(API & Integration) 		RESTful API 規範與協議設計 遵循標準 HTTP Methods (GET/POST/PUT/DELETE)、設計標準化 URI 命名、嚴格定義 HTTP 狀態碼 (200/201/400/401/403/404/500)。
資料交換格式解析 (JSON / XML) 能靈活處理複雜巢狀 JSON (Nested Arrays/Objects)、BOM 表格序列化與反序列化、XML 與 JSON 互相轉換、處理字元編碼 (UTF-8)。
API 工具除錯與自動測試 (Postman) 熟練建立 Postman 集合 (Collections)、配置環境變數 (Environments)、編寫 Pre-request Script 與 Tests 斷言腳本、匯出 Swagger/OpenAPI 規格。
API 鑑權安全 (JWT / OAuth2 / API Key) 實作或配置 JWT 簽發與驗證、Bearer Token 機制、OAuth 2.0 授權碼/客戶端憑證流程、API Key 配額限制與 HTTPS 憑證綁定。
API 閘道治理 (Rate Limit / Routing) 配置 API Gateway 路由轉發規則、設定 Rate Limiting 頻率保護、Spike Arrest 突發防護、CORS 跨網域設定、海外廠 IP 白名單過濾。
4. 軟體開發與
指令碼自動化
(Dev & DevOps) 		PowerShell 自動化維運腳本 撰寫 PowerShell 腳本自動備份資料庫、管理 AD 帳號、監控伺服器磁碟、排程刪除過期備份檔與自動推播錯誤通知。
Python 數據工程與自動化 (Pandas/Requests) 使用 Python 呼叫 REST API 擷取數據、使用 Pandas 進行資料清洗去重、連線 SQL Server / BigQuery 進行數據拋轉與格式轉換。
應用軟體程式碼維護 (C# .NET / Java) 能閱讀既有 ERP/MES 之後端程式碼（WinForms / ASP.NET MVC / C#）、能排查程式 Bug、能撰寫自訂業務功能模組。
版本控制與團隊協同 (Git / GitHub) 熟練使用 Git 指令（commit, push, pull, branch, merge, stash）、能排除分支衝突（Conflict）、使用 GitHub/GitLab 進行代碼版本留存。
容器化技術實務 (Docker 基礎) 能看懂與撰寫 Dockerfile、使用 docker-compose 啟動多容器應用、配置容器網路與 Volume 資料卷、檢視容器 Log 排查問題。
5. 商業智慧與
數據視覺化
(BI & Analytics) 		聯銓 Smart eVision 報表開發 熟悉聯銓 BI 資料集設定、SQL 查詢優化、多維度切片與交叉分析設計、圖表佈局與條件式格式化。
聯銓 BI 權限管理與定時派送 配置使用者群組、資料權限過濾（如海外廠長只能看該廠報表）、設定定時報表自動轉檔（PDF/Excel）與 Email 自動派送。
現代 BI 工具 (Power BI / Tableau) 建立星型維度模型 (Star Schema)、撰寫 DAX 計算量度 (Measures)、時間智慧函數 (Time Intelligence)、發布報表至雲端服務。
Excel 高階巨集維護 (PowerQuery / VBA) 能維護與修改生管複雜的 Excel VBA 巨集程式碼、使用 Power Query 進行跨檔案數據合併、設計進階樞紐分析表。
成衣製造 KPI 口徑定義與計算邏輯 清楚理解產線平衡率 (Line Balance Rate)、稼動率 (OEE)、標準工時 (SAM)、直通良率 (FTY) 之計算公式與各廠欄位對齊方式。
6. 基礎設施、
系統與跨國網路
(Infra & Network) 		Windows Server 系統管理維護 安裝配置 Windows Server 2016/2019/2022、角色功能安裝、檢視事件檢視器 (Event Viewer) 排查系統錯誤、磁碟擴展。
Active Directory 網域與目錄服務 網域控制器 (DC) 管理、組織單位 (OU) 規劃、群組原則 (GPO) 派送安全性設定、DNS 與 DHCP 伺服器配置維護。
虛擬化平台 (VMware ESXi / vCenter) VMware ESXi 叢集維運、建立虛擬機、分配 CPU/RAM/vDisk 資源、管理虛擬交換器 (vSwitch)、執行 vMotion 無中斷遷移。
交換器網路規劃 (VLAN / 路由) 實體交換器 (Cisco/Aruba) 設定、規劃 VLAN 隔離車間/辦公室/伺服器網段、配置 802.1Q Trunk 埠、靜態路由與廣播風暴防護。
跨國 Site-to-Site VPN ＆ SD-WAN 實務 建立與維護台北總部至海外三廠之 IPSec VPN 穿隧、監控跨國海纜延遲 (Ping RTT/Jitter)、設定 SD-WAN 流量分流策略。
邊界防火牆策略與 QoS (Fortinet) 熟練配置 FortiGate 防火牆策略 (Policies)、位址物件 (Address Objects)、NAT 連接埠轉發、配置 QoS 保障車間語音與 ERP 頻寬。
7. 車間物聯網與
機台邊緣設備
(Shopfloor & OT) 		工控電腦 (IPC) 與車間終端維護 研華 ARK / 觸控一體機維護、工控主機除塵防護、串列埠 (COM Port) 驅動安裝、Windows 10 IoT 作業系統維運。
工業通訊協定 (Modbus / RS-485 / OPC-UA) 理解 RS-485 差動訊號接線、Modbus RTU/TCP 暫存器讀取、PLC 數據擷取觀念，能除錯機台資料傳輸異常。
吊掛產線與 RFID 讀寫設備除錯 Impinj 或同級 RFID 讀寫器連網設定、天線增益與角度調整、排查衣服衣架 RFID 漏讀、通訊逾時重連。
特種機台介接 (自動裁床/模板機/貼合) 自動拉布機與裁床排料檔傳輸、自動模板機程式上傳、特種貼合機溫壓 IoT 感測器數據收集與異常排查。
邊緣離線自治機制 (Local Buffer / SQLite) 能配置現場機台或 Edge Proxy 的本地快取資料庫（SQLite/平坦檔）、海纜中斷時確保機台離線生產、復網自動批次追平。
8. 資訊安全、
備份與災變復原
(Security & BCP) 		企業備份架構落實 (Veeam / 3-2-1 原則) 熟悉 3-2-1 備份架構、配置每日完整與差異備份、設定備份加密金鑰、能獨立執行虛擬機與檔案層級之還原作業。
防勒索與不可篡改儲存 (WORM / Air-Gapped) 理解不可篡改備份池 (Immutable Repository / S3 Object Lock / WORM) 設定，防止勒索病毒橫向感染加密備份檔案。
端點安全防護 (EDR / 防毒主控台派送) 管理防毒主控台（趨勢/卡巴/CrowdStrike）、排查端點惡意程式隔離警報、監控全廠機台更新率、配置隨身碟 (USB) 讀寫管制。
身分安全與多因子認證 (MFA / 2FA) 推廣與配置 Authenticator App 雙因子認證、強制 VPN 撥接啟用 MFA、執行特權管理者帳號定期更換密碼與離職清查。
災難復原指標理解與實測 (RTO / RPO) 清楚量化所管轄系統之資料遺失容忍極限 (RPO) 與系統重啟時間 (RTO)、能編寫災難復原操作手冊 (Runbook) 並實際演練。

外部廠商與系統整合商 (SI) 管理 能審查原廠合約工作範疇 (SOW)、把關顧問公司交付進度、能提出精確的架構修訂要求，避免被廠商牽著鼻子走。
