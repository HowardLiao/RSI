CHAPTER 03 · AI IN SDLC (AISDLC) FRAMEWORK

第參章：AI in SDLC 雙軌開發與 SI 廠商交付治理體系

結合 DevSecOps 7 階段輪盤與 AI 模型 4 象限輪盤，確立外部 SI 實施隊（6～8人）驗收標準，杜絕技術債。

🛡️
軟體工程核心原則：開箱即用交鑰匙樣板 (Turnkey Template)
外部 SI 實施隊在 2027 Q1–Q2 首廠建置期退場後，必須保證信源內部 IT 團隊能夠 100% 自主維運、自主除錯並自行在第二、第三產區複製。嚴禁使用任何廠商私有封閉代碼、未揭露第三方軟體或個人帳號綁定。
維度與階段 傳統 SDLC 做法 信源 AI in SDLC (AISDLC) 雙軌標準 驗收查驗機制 (Quality Gate)
1. 需求與規格審查 業務提出口頭或 Word 需求，規格變更多且無架構師參與。 以 AI 輔助建立標準 User Story 與 OpenAPI 3.0 介面規格，架構師進行邊界審查。 周副總與架構負責人核定首批串接範圍定義書。
2. 安全編碼與 SAST 工程師個人撰寫，密鑰可能寫死在代碼中，依賴上線前人工檢查。 Codex 輔助生成代碼，強制禁止寫死金鑰；CI/CD 整合 SonarQube 與 Trufflehog 阻斷提交。 高危漏洞為 0，密鑰掃描 100% 透過 HashiCorp Vault 存取。
3. API 測試左移 (BOLA) 上線後靠人工點擊測試，缺乏影子 API 檢測與權限越權防禦。 自動生成端點 fuzzing 測試用例，重點防禦 BOLA (物件級授權無效) 與批次爆破。 通過 OWASP API Top 10 自動化測試矩陣。
4. AI 模型微調與對齊 直接呼叫公有雲 API，無法掌握 Prompt 洩漏風險與輸出偏差。 建立 Llama-Guard 3 雙向防護欄，測試注入攻擊 (Prompt Injection)，驗證 RAG 溯源標籤。 敏感資料遮罩率 100%，RAG 置信度分數 ≥ 0.90。
5. 邊緣部署與離線驗收 假設網路永遠在線，海纜中斷時產線立即停擺。 驗證 DuckDB 本地快取，拔網線實測 48～72 小時連續生產，復網後 Delta 差分自動回傳。 海外三廠斷線壓力測試，結算資料 100% 無遺失對齊。
6. 交付物與維運移轉 廠商交付 Word 報告即算結案，內部人員無法自主排障。 交付 Terraform / Bicep IaC 腳本，信源 IT 在測試區獨立「一鍵重建部署成功」始准驗收。 內部同仁獨立執行災難復原演練 (RTO < 2h)。
CHAPTER 04 · INTERNAL POLICY & GOVERNANCE REGULATIONS

第肆章：企業級生成式 AI 與自主 Agent 治理管理辦法 (ENT-AI-GOV-001)

整合 ISO 27001、ISO 42001 與金管會核心指引，確立 A0～A4 Agent 權限分級、品牌 IP 無菌室與緊急熔斷機制。

🏷️ A0～A4 AI Agent 自主性管制標準
權限劃分
  • A0 級 (唯讀查詢型)：僅得查詢公開資訊或授權之內部 L1 文檔，無系統寫入與 API 呼叫權限。
  • A1 級 (受控建議型)：可生成報表摘要或工單草稿，必須由人工審閱後手動複製執行。
  • A2 級 (人機協同型 · 核心上限)：可調用預核准之 API，但生產投產、採購發單與財務報銷強制需主管電子簽名。
  • A3 級 (邊界自主型)：僅限於預警通知、定期對帳與非核心數據備份，且具備嚴格執行上限。
  • A4 級 (完全自主型)：全集團生產、排程、財務核心系統嚴格禁止開放 A4 特權！
🔒 品牌客戶智財無菌室 (IP Clean Room)
智財保護
  • 租戶實體隔離 (ABAC)：以 Microsoft Entra ID 屬性存取控制，嚴格隔離 Nike、Lululemon 與其他品牌客戶版型資產，嚴禁交叉洩漏。
  • 去識別化前置處理：款式結構圖上傳至 AI 平台前，自動遮罩品牌標籤、客戶款式編號與製造廠區識別碼。
  • Zero Data Retention (ZDR)：要求外部 AI 供應商簽署資料不落地與不用於模型重訓協定。
  • 外包廠商隔離存取：外部打版與原料協力廠一律採無客戶端虛擬桌面 (Clientless Portal)，僅限線上審閱，嚴禁原始檔案下載。
⚡
緊急熔斷機制 (Emergency Kill Switch) 與 1 小時通報 SLA：
當 AI 模型發生異常幻覺（如給出嚴重錯誤的裁片排料參數、產生越權調用告警）時，管理員可在 30 秒內啟動中央 Kill Switch，API 網關立即切斷 AI 路由並自動降級回人工審核模式；同時觸發 1 小時資安通報 SLA，召集架構主管（元翔）與執行負責人（Howard Liao Ph.D.）排查日誌。
