業務實體關聯說明

  • FabricRelaxDetail 與 FabricRelaxBarcode：採「一對多實體聚合 (Composition)」，一張鬆布單包含多筆布捲條碼明細，每捲包含缸號 (LotNo)、長度 (Actual_Qty)、門幅 (Actual_Width) 與實測碼重。
  • FabricRelaxCarInfo 實體鬆布車關聯：鬆布車載有 RFID 晶片，在經過 AGV 或立庫轉運時，與實體停車位 (WmsBinLocation) 即時關聯。
  • 手持終端 (PDA)：透過 Android_API_Response 與 PdaReceiveOrder 實現副料進出庫驗貨閉環。

介面安全與通訊特性

  • 通訊協定：全部採 POST application/json，無 URL Query Parameter 洩漏敏感資訊。
  • 狀態回傳介面：所有介面統一實作 ApiResponse 或 Android_API_Response，包含 Is_Valid 狀態碼、Total、Success、Fail 統計指標。

成衣製造流程鏈路

  • 裁斷中心 (Cutting Center)：以 CutOrder (CO_No) 為核心，展開 CutOrder_Marker_Info 與 CutColor（記錄各色布料拉布層數 Layer_Qty）。
  • 裁片入庫 (CutPiece_StockIn)：與立庫系統 (GIL CutAsRs) 聯動，將裁片分包捆綁送入裁片中繼庫。
  • 車縫與出貨：由 SewingProduceDailyQty 按產線/工段回報計數，最終匯總至 SalesOrderShip 進行成品出口發貨。

UHF RFID 與實體資產雙重管理

  • UHF RFID 標籤綁定：全廠萬餘台縫紉機、平車、拷克車均以 Machine_UHF 與 Machine_AssetNumber 雙軌識別。
  • 維修流程狀態機：報修 (RepairStart) → 派工 (RepairDispatch) → 完工 (RepairEnd) → 主管簽核 (RepairConfirm)，全程紀錄於 RepairMaster。
  • 盤點作業 (TakeInventory)：手持 RFID 終端整排掃描，透過 TakeInventoryDetail.IsScaned 自動比對盤盈盤虧。
