🏛️ 蜂巢計畫 (Project Hive) 實施藍圖與治理規範

本架構由周文津 副總 (Executive Sponsor) 擔任計劃主持人，由 Howard Liao Ph.D. (Lead Architect & C-Level Advisor) 擔任執行負責人。針對信源全球跨國製造業（台北內湖總部、越南同奈廠、柬埔寨柴楨廠）與香港 AWS 雲端進行四階層深度整合，落實「整合運用・智能營運」之年度戰略目標。

  • 邊緣離線自治 (Edge Offline Autonomy)：海外廠區（RDV 與 RDG）採用輕量級邊緣叢集（K3s + SQLite/Redis 本地緩衝），當跨國海底電纜或 WAN 線路意外中斷時，廠區產線工單、PLC 通訊與感測器採集皆能保持自主運轉至少 72 小時，待線路恢復後自動啟動佇列重傳補正機制（Backfill Resync）。
  • 四層安全防禦與微切分 (Micro-segmentation)：全網實施安全微切分，將 OT 產線網段（PLC/感測器）、IT 辦公網段、核心資料庫網段（SAP HANA）、以及 OOB 帶外硬體管理網段（iDRAC/IPMI）嚴格分流，外部進入核心 DB 僅限 API Gateway 於白名單 Port 30015 通訊。
  • 擬真實體伺服器機箱視覺化 (Hardware-Aware Visual Standard)：揚棄傳統軟體方框代稱，採用包含 1U/2U 深色金屬前面板、熱插拔硬碟抽取槽（Drive Bays）、雙通道 10GbE SFP+ 光纖網口、狀態 LED 燈號之高解析向量圖與 Draw.io XML，具備可直接指導機房上架佈線之實務價值。
  • 全閃存集中儲存與無單點故障 (Zero Single Point of Failure)：台北核心機房配置 Dell Unity 480XT 雙主動儲存陣列，以雙通道 10GbE iSCSI 提供 ESXi 叢集高速虛擬磁碟空間；對外透過雙網際網路 ISP 與雙軌 IPSec VPN 確保 99.99% 高可用性。
